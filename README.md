# Advanced Simple & Scientific Calculator

A sleek, responsive, and secure web calculator with a modern Glassmorphic UI that easily switches between standard arithmetic and scientific functions.

 Tech Stack
- HTML5 (Semantic structures & data attributes)
- CSS3 (Flexbox, CSS Grid, Custom Variables, Fluid Transitions)
- JavaScript (Event Delegation & RegExp input sanitization)
